תסריט מדריך (למדריכים בלבד)
מטרה: תרגול מלא של כניסה–שיחה–יציאה בסימולטור SquareTalk, בלי לגעת בסופטפון האמיתי. לפני השיעור: • ודאו שכל נציג רואה בראש העמוד את השלוחה שהוגרלה ואת סיסמת התרגול (מזויפת — לתרגול בלבד, תבנית Atza+שלוחה+!). • הדגישו: הסימולטור בלבד — לא להתחבר לסופטפון אמיתי בשלב זה. מהלך (~15–20 דק׳): 1. סרטון / הדגמה קצרה (3–4 דק׳). 2. תחנה 1: Edit Account → השלוחה שהוגרלה + סיסמה מהמסמך → Online. 3. תחנה 2: העתקת מספר לפני Answer (כישלון מכוון אם עונים קודם — שיעור!). 4. תחנה 3: Hold → חיוג סניף → End → Last Call. 5. תחנה 4: Exit בלבד (לא X). קריטריון מעבר: ארבעת ה־✓ ירוקים בפס ההתקדמות («✓ נכון!» ירוק בסיום כל תחנה). דגלי ניחוש (תחנות פעולה): • כל פעולה שגויה בתחנה נספרת (סיסמה/שדות שגויים ב־Save, Answer בלי העתקה, Decline/סגירת פופאפ, סדר שגוי ב־Hold/חיוג/End/Last Call, סגירה ב־X במקום Exit). • עד 2 טעויות = הודעת טיפ רגילה. בטעות ה־3 באותה תחנה — דגל «ניחוש», אזהרה כתומה ונעילת הסימולטור של התחנה ל־15 שנ׳ עם ספירה לאחור. • דגל «מהיר מדי» כבוי בשיעור הזה — פעולות רב־שלביות לא ניתנות לניחוש מהיר. • בסיום: «דגלים: X». יומן ב־localStorage: atzaAcademy.lesson01-telephony.log. ספים: MAX_WRONG=3, LOCK_SEC=15, FAST_SEC=4. שגיאות נפוצות: • סיסמה עם רווח / אותיות הפוכות → הסימולטור יציג שגיאה. • Answer בלי העתקה → איפוס הפופאפ. • סגירת חלון ב־X ביציאה → הודעת כשלון.
